# TamizChat

کلاینت ویندوزی [TamizChat](https://github.com/<you>/tamizchat-server) — یک چت
صوتی و متنیِ self-hosted: اتاق‌هایی که قبل از ورود می‌بینید داخلشان چه خبر است،
صدا و تصویر، اشتراک صفحه، تخته‌ی نقاشی مشترک، فایل، و بات‌های موسیقی.

با WinUI 3 روی .NET 10 ساخته شده. به‌صورت یک پوشه‌ی ساده با رانتایم خودش عرضه
می‌شود، پس چیزی لازم نیست از قبل نصب باشد و پای هیچ حساب استوری در میان نیست.

## نصب

فایل `TamizChat-x.y.z-setup.exe` را از صفحه‌ی ریلیزها بگیرید و اجرا کنید.

به‌صورت پیش‌فرض برای همان کاربر نصب می‌شود، پس ویندوز دسترسی مدیر نمی‌خواهد.
انتخاب گزینه‌ی «نصب برای همه‌ی کاربران» در ویزارد هم مشکلی ندارد.

**پیش‌نیاز:** ویندوز ۱۰ نسخه‌ی 2004 (بیلد 19041) یا جدیدتر، ۶۴ بیتی. همین — دات‌نت
و Windows App SDK داخل خود برنامه هستند.

installer نمی‌خواهید؟ پوشه‌ی `TamizChat-win-x64` را از ریلیز بردارید، هر جا خواستید
بگذارید و `TamizChat.exe` را اجرا کنید.

## اولین اجرا

۱. **Settings ← نام شما.** همان چیزی که بقیه در اتاق می‌بینند.
۲. **Servers ← افزودن سرور.** آدرسش، مثلاً `chat.example.com` یا
`192.168.1.50:8080`. اگر سرور رمز دارد، همین‌جا پرسیده می‌شود.
۳. **Join** بزنید و با دابل‌کلیک وارد یک اتاق شوید.

هویت شما یک UUID است که برنامه یک بار می‌سازد و نگه می‌دارد. روی هر سروری همان
آدم هستید و با تغییر نام هم عوض نمی‌شود — به همین دلیل است که اگر صدای کسی را کم
کنید، بعد از تغییر نامش هم کم می‌ماند.

## چه کارهایی می‌کند

**اتاق‌هایی که تویشان را می‌بینید.** صفحه‌ی سرور همه‌ی اتاق‌ها و آدم‌های داخلشان
را نشان می‌دهد، پس قبل از ورود می‌دانید گفت‌وگو کجاست. با دابل‌کلیک وارد شوید.

**صدا.** به‌محض ورود به اتاق، به بخش صوتی‌اش هم وصل می‌شوید. نوار پایین صاحب
میکروفون و اسپیکر است. اگر خودتان را میوت یا کر کنید، روی آواتارتان یک نشان
می‌افتد که همه می‌بینند — و نشان بقیه را هم شما می‌بینید.

**تصویر و اشتراک صفحه.** دوربین یا یک پنجره/نمایشگر انتخابی، در همان خانه‌ای که
آواتار بود.

**تغییردهنده‌ی صدا و ساندبورد.** بم، سنجابی، رباتیک، رادیویی — روی میکروفون خودتان
و داخل همین پروسه اعمال می‌شود، پس هیچ درایور صوتی مجازی نصب نمی‌شود. کلیپ‌های
ساندبورد فایل‌های خودتان‌اند و بقیه هم آن‌ها را می‌شنوند.

**تخته‌ی نقاشی.** مشترک، برای هر اتاق، و خط‌به‌خط همان‌طور که کشیده می‌شود
استریم می‌شود.

**چت و فایل.** متن، استیکر، و ارسال فایل و عکس. محتوای اتاق — پیام، فایل، نقاشی —
عمداً موقتی است و با خروج آخرین نفر پاک می‌شود.

**اورلی‌ها.** فهرست اعضا و پیام‌ها به‌صورت پنجره‌های شفاف و کلیک‌نشدنی روی
بازی‌های تمام‌صفحه شناور می‌شوند.

**پنل مدیریت.** برای ادمین‌ها: کاربران و نقش‌ها، بن‌ها، اتاق‌ها و بات‌ها — همراه
با طراح بصری تگ نقش. کارهای روزمره‌ی یک سرور دیگر SSH نمی‌خواهد.

**بات موسیقی.** بات مثل یک کاربر واقعی وارد اتاق می‌شود و پلی‌لیست پخش می‌کند.
آهنگ‌ها را از پنل مدیریت آپلود کنید؛ برنامه موقع ارسال آن‌ها را به Ogg/Opus تبدیل
می‌کند و همین است که به سرور اجازه می‌دهد بدون دست‌زدن به صدا پخششان کند.

## داده‌های شما کجاست

`%LOCALAPPDATA%\TamizChat`

| فایل | چیست |
|---|---|
| `settings.json` | نام، هویت، تم، دستگاه‌ها، ولوم‌ها، کلیدهای میان‌بر |
| `servers.json` | سرورهای ذخیره‌شده |
| `sounds\` | کلیپ‌هایی که به ساندبورد اضافه کرده‌اید |

هنگام حذف برنامه پرسیده می‌شود که این پوشه هم پاک شود یا نه؛ اگر بگویید نه،
می‌ماند.

اگر برنامه یک بار بی‌مقدمه بسته شد، فایل `crash.log` را کنار `TamizChat.exe`
می‌گذارد — سریع‌ترین راه برای رفع آن باگ همین فایل است.

## بیلد از سورس

**پیش‌نیاز:** .NET 10 SDK، ویندوز SDK نسخه‌ی 10.0.26100، و ویژوال استودیو ۲۰۲۲ یا
خط فرمان.

</div>

```powershell
git clone https://github.com/<you>/tamizchat.git
cd tamizchat
dotnet build tamizchat.slnx -p:Platform=x64
```

<div dir="rtl">

اجرا:

</div>

```powershell
.\tamizchat\bin\x64\Debug\net10.0-windows10.0.26100.0\win-x64\TamizChat.exe
```

<div dir="rtl">

بیلد ریلیز، که همان پوشه‌ی قابل توزیع هم هست:

</div>

```powershell
dotnet build tamizchat\tamizchat.csproj -c Release -p:Platform=x64
```

<div dir="rtl">

> **از `dotnet build` استفاده کنید، نه `dotnet publish`.** برای یک برنامه‌ی WinUI
> بدون بسته‌بندی، publish فایل‌های XAML کامپایل‌شده (`.xbf`) و `.pri` برنامه را
> جا می‌اندازد و نتیجه با `XamlParseException` بالا می‌آید و می‌میرد. پوشه‌ی بیلد
> Release خودش کامل و self-contained است.

## ساخت installer

اسکریپت installer کنار مخزن‌های کلاینت و سرور، در پوشه‌ی `installer/` است و به
[Inno Setup 6](https://jrsoftware.org/isdl.php) نیاز دارد.

</div>

```powershell
cd installer
.\build.ps1                  # هم برنامه را می‌سازد هم setup را
.\build.ps1 -SkipApp         # فقط setup، با استفاده از dist\ موجود
.\build.ps1 -Version 1.1.0   # درج نسخه
```

<div dir="rtl">

خروجی در `dist\installer\` ساخته می‌شود. Inno Setup ترجمه‌ی فارسی همراه ندارد؛
اگر فایل `Persian.isl` را از
[بسته‌ی زبان‌هایش](https://jrsoftware.org/files/istrans/) در پوشه‌ی `Languages`
آن بگذارید، installer فارسی را هم پیشنهاد می‌دهد.

## ساختار پروژه

| پروژه | چیست |
|---|---|
| `tamizchat` | خود برنامه‌ی WinUI 3: صفحه‌ها، کنترل‌ها، اورلی‌ها، سرویس‌ها |
| `TamizChat.Core` | کلاینت پروتکل و نشست مدیا. بدون وابستگی به رابط کاربری |
| `TamizChat.Audio` | ضبط، پخش، افکت صدا، تبدیل Opus |
| `TamizChat.Simulator` | ابزار کنسولی که نقش کاربران دیگر را بازی می‌کند |

اینکه `TamizChat.Core` یک کتابخانه‌ی ساده است عمدی است: هم می‌شود از آن در یک
رابط کاربری دیگر استفاده کرد، هم پروتکل را از کد رابط جدا نگه می‌دارد.

## شبیه‌ساز

تست یک برنامه‌ی چت به‌تنهایی سخت است، پس `tamizsim` نقش بقیه را بازی می‌کند:

</div>

```powershell
tamizsim check                  # یک بار وصل شو، بگو سرور چه گفت، خارج شو
tamizsim run    Bob   Lobby     # مثل کسی که در اتاق نشسته
tamizsim talk   Alice Lobby     # یک تُن صدا در اتاق پخش کن
tamizsim listen Carol Lobby     # آنچه می‌رسد را پخش کن، برای تست میکروفون خودتان
tamizsim video  Dave  Lobby     # الگوی تصویری متحرک، بدون نیاز به وبکم
tamizsim paint  Erin  Lobby     # یک خط استریم‌شده روی تخته بکش
tamizsim bots   Admin           # کل مسیر مدیریت بات را برو و بررسی کن
tamizsim convert song.mp3       # زمان تبدیل Opus خود کلاینت را اندازه بگیر
```

<div dir="rtl">

متغیر `TAMIZSIM_SERVER` مقدار `localhost:8080` را جایگزین می‌کند و
`TAMIZSIM_SECONDS` مدت اجرا را محدود می‌کند. هر نام به یک هویت ثابت نگاشت می‌شود،
پس اتصال دوباره مثل برگشتن همان آدم دیده می‌شود.

## عیب‌یابی

**پنجره باز می‌شود و بلافاصله بسته می‌شود.** فایل `crash.log` کنار فایل اجرایی را
بخوانید — نام استثنا داخلش هست.

**هیچ صدایی از کسی نمی‌آید.** دستگاه خروجی را در Settings چک کنید و مطمئن شوید
کر (deafen) نیستید — دکمه‌ی Speaker در نوار پایین.

**کسی صدای من را نمی‌شنود.** دستگاه ورودی و نشانگر سطح صدا را در Settings ببینید.
وقتی میکروفون کار می‌کند، آن نشانگر حرکت می‌کند — قبل از اینکه چیزی ارسال شود.

**اصلاً به بخش صوتی وصل نمی‌شود.** ممکن است سرور LiveKit را تنظیم نکرده باشد؛ چت
متنی در هر صورت کار می‌کند. از اپراتور سرور بپرسید.

**آپلود یک آهنگ کمی طول می‌کشد.** اول به Opus تبدیل می‌شود: حدود هفت ثانیه برای
یک آهنگ چهاردقیقه‌ای. نوار پیشرفت هم تبدیل و هم آپلود را نشان می‌دهد.
